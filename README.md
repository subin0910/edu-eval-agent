# 📘 Edu Eval Agent

### AI 기반 영어 시험 자동 채점 · 성적 분석 · 맞춤형 학습문제 생성 서비스

**Edu Eval Agent**는 영어 학원 선생님과 원장님을 위한 웹 기반 평가 도우미입니다. 영어 시험 문제지, 정답·배점표, 학생 OMR 응답 파일을 업로드하면 자동 채점부터 성적 분석, 문항별 오답 현황 파악, 학습 목표에 맞춘 유사문제 생성까지 하나의 서비스에서 진행할 수 있습니다.

> **서비스 이용:** Streamlit 배포 URL 등록 예정  
> **개발:** 윤수빈 · 202334498  
> **프로젝트:** 가천대 AI Agent 개발 부트캠프 최종 프로젝트

---

## ✨ 주요 기능

### 1. PDF 정답표 기반 자동 채점

- **문제지 PDF**, **정답·배점 PDF**, **학생 OMR Excel**을 업로드하고 `분석 시작` 버튼을 누르면 채점을 수행합니다.
- 업로드된 정답 PDF에서 문항 번호·정답·배점을 직접 추출해 채점에 사용합니다.
- 학생별 총점과 문항별 정오 여부를 계산하며, 파일에 포함된 학생 수와 문항 구성을 기준으로 분석합니다.
- 추출된 정답표와 학생별 채점 결과를 화면에서 확인할 수 있습니다.

### 2. 성적 분석 대시보드와 Excel 리포트

- 전체 학생의 **평균, 중앙값, 모집단 표준편차**를 제공합니다.
- **오답률이 높은 문항**, 문항별 오답 학생 수 및 오답률을 조회할 수 있습니다.
- 학생별 점수와 각 문항의 정오 여부를 확인할 수 있습니다.
- `채점 결과 Excel 다운로드`로 분석 결과를 저장할 수 있습니다.

**Excel 리포트 구성**

| 시트 | 주요 내용 |
| --- | --- |
| 전체 성적 요약 | 평균·중앙값·표준편차·오답 상위 문항 |
| 학생별 채점 결과 | 학생별 총점과 문항별 정답 여부 |
| 문항별 분석 | 정답률·오답률·오답 학생 수 |
| 추출된 정답표 | PDF에서 추출한 문항 번호·정답·배점 |

### 3. 자연어 성적 분석 챗봇

통계 프로그램을 직접 다루지 않아도 선생님이 **평소 말하듯 질문**할 수 있습니다.

- 전체 평균·중앙값·표준편차 조회
- 최저점 학생 및 특정 학생의 점수 조회
- 학생별 오답 문항 조회
- 오답률 상위 문항을 원하는 개수만큼 조회
- 특정 문항의 정답·배점·오답 현황 조회
- **“그 학생”, “그 문제”, “그중 네 번째”**와 같은 동일 대화 세션의 후속 질문 이해
- 서비스 사용 방법 안내 및 일반적인 영어 학습 질문 응답

**예시 질문**

> 학생들 이번 시험 평균이랑 중앙값이 뭐야?  
> 가장 성적이 저조한 학생은 누구야?  
> 900학생은 몇 점이야? 그 학생이 틀린 문제도 알려줘.  
> 가장 많이 틀린 문제 5개 알려줘. 그중 네 번째는 몇 점짜리야?

### 4. 학습 목표 기반 AI 유사문제 생성

단순히 원본의 소재를 다시 쓰는 대신, 원본 문항에서 평가하는 **학습 목표와 풀이 능력**에 초점을 맞춰 새 문제를 생성합니다.

- 오답이 가장 많은 문항 또는 선생님이 지정한 문항을 바탕으로 생성
- 어법·어휘·주제 찾기·함축 의미·빈칸 추론·요약문 완성·안내문 비교 등 문항 유형에 맞춘 생성
- PDF에 있는 지문·표 등 원본 문항 자료를 참고
- 새 지문과 선택지, 정답, 해설 및 학습 포인트 제공
- **한 문항씩 생성**하거나 **여러 문항을 한 번에 생성**하는 방식 지원(다중 생성은 처리 시간이 더 길 수 있음)

**예시 질문**

> 학생들이 가장 많이 틀린 문제와 유사한 유형으로 문제 하나 만들어줘.  
> 29번과 같은 문법 요소를 연습할 수 있는 문제 만들어줘.  
> 28번과 유사한 문제 만들어줘. 표도 포함해 줘.  
> 21번과 33번의 유사문제를 하나씩 만들어줘.

### 5. 문항별 학습 목표와 보충학습 방향 분석

- 문항의 유형과 평가하는 능력을 설명합니다.
- 해당 문항에서 **학생들이 어려워했을 가능성이 있는 부분**과 보충학습 방향을 제시합니다.
- 오답 수만으로 실제 오개념이 확정되는 것은 아니므로, 가능한 원인과 확인된 통계 정보를 구분하여 안내합니다.

### 6. 근거 기반 응답과 대화 관리

- 성적·배점·오답 현황은 업로드된 자료를 분석한 결과에서 조회합니다.
- 출결·전화번호·실시간 날씨처럼 업로드 자료에 없는 정보는 임의로 만들어 답하지 않습니다.
- 시스템 설정, API 키, 내부 지침 등 비공개 정보에 대한 요청은 제한합니다.
- 채팅 내역과 분석 상태는 사용자의 현재 웹 세션에서 관리합니다.

## 🚀 사용 방법

1. 웹사이트의 **채점 및 AI 분석** 페이지로 이동합니다.
2. 왼쪽 사이드바에서 **시험 문제지 PDF**, **정답·배점 PDF**, **학생 OMR Excel(.xlsx)**을 업로드합니다.
3. **분석 시작**을 클릭합니다.
4. 화면에서 평균·중앙값·표준편차, 학생별 점수, 문항별 오답 순위와 추출된 정답표를 확인합니다.
5. **채점 결과 Excel 다운로드** 버튼으로 리포트를 저장합니다.
6. 아래 **AI 평가 도우미** 채팅창에서 성적을 질문하거나 보충학습 문제를 생성합니다.

> 유사문제는 AI가 생성한 교육용 초안입니다. 실제 시험·수업·인쇄에 사용하기 전 선생님이 문항과 정답·해설을 최종 확인해 주세요.

## 💻 로컬 실행

Python 가상환경을 생성하고 필요한 패키지를 설치합니다.

```bash
python -m venv .venv
# Windows Git Bash
source .venv/Scripts/activate
python -m pip install -r requirements.txt
```

프로젝트 루트에 `.env` 파일을 생성해 API 키와 모델 설정을 입력합니다.

```dotenv
OPENAI_API_KEY=your_openai_api_key
ROUTER_MODEL=gpt-4.1
GENERATOR_MODEL=gpt-5.4
SINGLE_GENERATION_TIMEOUT=17
BATCH_GENERATION_TIMEOUT=110
```

앱 실행:

```bash
streamlit run app.py
```

브라우저에서 `http://localhost:8501`로 접속합니다. 자동 테스트는 다음 명령으로 실행할 수 있습니다.

```bash
python -m pytest -q
```

## ☁️ 배포

Streamlit Community Cloud에서 GitHub 저장소를 연결하고, 진입 파일을 `app.py`로 선택합니다. **앱의 Secrets 설정에 API 키와 필요한 환경 변수를 등록**한 후 배포합니다. 비밀키, 실제 학생 OMR 및 개인정보는 공개 GitHub 저장소에 커밋하지 않습니다.
